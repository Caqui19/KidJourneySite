# KidJourney

Site do KidJourney feito com React e Vite.

## Rodar o projeto

```bash
npm install
npm run dev
```

## Arquivos principais

- `src/pages` guarda as telas do site.
- `src/components` guarda os formulários e partes reutilizadas.
- Cada tela tem seu próprio arquivo CSS.
- `src/firebase.js` configura o Firebase.
- `src/auth.js` cadastra os usuários e salva os dados no Firestore.
- O formulário de parceiros abre um e-mail para a equipe analisar o pedido.
